# 离线标准观测质量复核

`resistor_flow.review.review` 对实测归档的一个**指定历史版本**、一个采样
窗口内的标准观测做一次只读复核：这些观测各自通过发布检查，并不代表它们能
共同解释同一接线上的压差；本接口回答“整段是否自洽”“若仅隔离一座记录站能
否恢复自洽”“哪些站符合这一条件”以及“失去观测的测点应补测在什么区间”。

复核不新增命令行、不操作设备、不计算电流或发热，也不使用网络标称电位替代
现场读数。数值一律来自归档标准观测与调用方给出的半宽，用精确有理数判断，
等于区间边界算满足。本模块不导入求解器（`nodal` / `service`），不推进版本、
不写归档；同一历史版和同一半宽表的结果不受归档后来推进影响。

## 接口

```python
from resistor_flow.review import review, ReviewInputError

result = review(store_dir, run_id, version, window, half_widths)
```

- `store_dir`：`measurements.publish` 使用的归档目录。
- `run_id`：运行 ID（沿用本仓 ID 规则）。
- `version`：该运行**已发布的正整数**版本号；未知运行或历史版报输入错误，
  不回落当前版。
- `window`：`[start_tick, end_tick)`，沿用归档口径的端点，必须非空。
- `half_widths`：`{resistor_id: 有界十进制字符串}` 的对称绝对误差半宽；
  不得小于零，`"0"` 表示精确。必须**恰好**覆盖该窗口内标准观测出现的电阻
  ID（缺失、多余都报错；窗口内没有标准观测时须为空表）。同一电阻在整个窗口
  使用同一半宽。

取数只来自该版本窗口内的**标准观测及其完整 `sources`**。冲突键、未绑定读数
与裸原始行都不参加，也不能在隔离后重新裁决成观测。网络只取该运行首版固定的
电阻 ID 与有序端点 `a/b`；不使用其标称电位、电阻值，也不要求没有实测的支路
参与。

## 裁决

对每个有观测的 tick，要求存在一套**共同**节点电位，使每条观测的
`V(a)-V(b)` 落在归档值加减半宽的闭区间 `[volts-w, volts+w]` 内。不同 tick
的电位互不约束。

1. 初始窗口每个 tick 都自洽 -> `status = "as_published"`，原样交付全部
   窗口内观测行，`candidates` 为空。
2. 否则从窗口标准观测出现过的站中找**全部**合格候选：分别假设隔离一座站，
   从窗口所有行移除该站的来源（含同一行上的多条来源）。一行只要还有其他来源
   支持，就仍以**原数值和原半宽**继续约束；只有失去全部来源的行才撤下。
   单独隔离该站后窗口每个 tick 都自洽，该站才是合格候选。
   - 恰好一个候选 -> `status = "isolated_single_station"`，交付数据。
   - 没有候选 -> `status = "no_qualified_station"`，不交付任何行或补测区间。
   - 不止一个候选 -> `status = "ambiguous_station"`，不交付任何行或补测区间。

不按 tick 各选一座站、不通过扩大半宽过关、不在多个候选中按字典序择一。
候选只表示“存在一种解释”，不表示已证实的故障。

## 输出

```python
{
  'run_id': ..., 'version': ..., 'window': [start, end],
  'status': 'as_published' | 'isolated_single_station'
            | 'no_qualified_station' | 'ambiguous_station',
  'candidates': [...],                 # 排序后的候选站 ID；原样可用时为空
  # 仅 as_published / isolated_single_station：
  'rows': [
    {'tick': ..., 'resistor_id': ..., 'volts': ...,     # 归档原精确字符串
     'sources': [[station, row_id], ...]},              # 保留现有顺序
    ...
  ],
  # 仅 isolated_single_station：
  'retests': [
    {'tick': ..., 'resistor_id': ...,
     'isolated_sources': [[station, row_id], ...],      # 被隔离站的来源
     'inferred': True,                                  # 明确标识为推断
     'min_volts': '...' | 'unbounded',
     'max_volts': '...' | 'unbounded'},
    ...
  ],
}
```

- `rows` 与 `retests` 各自按数值 `tick`、`resistor_id` 升序；来源保留归档
  顺序。
- `rows` 只含仍受支持的行：保留键与原精确值，来源为去掉被隔离站后的完整
  剩余来源。
- `retests` 每个被撤下的原行一项。区间是该 tick **仅凭剩余观测**可达的
  `V(a)-V(b)` 最小、最大值；两端都有有限界时用现有有理数字符串表达，任一端
  无有限界时该端为字符串 `"unbounded"`。区间恰好描述该键的可能范围，不沿用
  被撤值或误差，也不要求不同撤下键的端点同时可达。补测项独立标识为推断，
  绝不作为实测数据回填。
- 没有候选或候选不唯一时，结果不含 `rows` / `retests` 键。

## 失败约定

结构/类型/ID/tick 非法、窗口为空或端点越界、半宽表非有界十进制字符串、
半宽为负或未恰好覆盖、未知运行、未知或非正整数版本，均抛
`ReviewInputError`（`ValueError` 子类），不返回任何裁决或数据，也不改动
归档。

## 可复现验收

```sh
# 在本仓根目录
python3 -I -m unittest discover -s tests -v
```

`tests/test_review.py` 覆盖：

1. 两个矛盾 tick（`a-b-c` 与 `d-e-f` 三角形，长边仅由 A 支持）在同一窗口
   时只准隔离 A，两处撤下键分别补测 `[3,7]` 与 `[5,5]`；同窗口含一个原本
   自洽的 tick、一条 A 独自支持且撤下后无界的行、一条 A 与他站共同支持的
   行（只删 A 的来源）。随后发布新版给第二个矛盾 tick 加一条同值来源，整段
   变为无合格站且不泄漏任何行或补测区间；旧版结果逐字段不变。
2. 反向端点与平行测点、闭区间刚好相接、多条剩余路径共同收紧补测边界、
   A/B/C 三候选时 ambiguous 不交付、冲突/未绑定读数不补进结果、合法窗口内
   无标准观测（半宽表须为空）、非法半宽表与版本。逐项检查交付来源与精确
   区间，不只断言状态。
3. 性能用例：400 个连续 tick、每 tick 200 条标准观测；6 个三角形测点中
   两个长边由 A 独自支持、四条短边由 B/C/D/E 支持，其余 194 个测点组成与
   三角形分离的连通分量、各由 194 个站支持，半宽全为 0。仅最后两个 tick
   各让一个长边读数为 1。返回唯一候选 A、79,200 条保留行与 800 条 `[0,0]`
   补测项（含先前完全自洽时刻的行）。用例内自行生成归档，发布准备不计时；
   以 CPython 单核 Linux 的新进程读取已备归档并计时，从进入接口到核对结果
   为 CPU 时间，须不超过 25 秒。本机实测约 4.4 秒。该时间线只针对这一负载，
   不承诺所有合法输入同耗时。
