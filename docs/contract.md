# 有界直流电阻网络

电路实验数据分析者输入 nodes（1..60）、resistors（0..300）。节点唯一id，voltage为固定理想电位的十进制字符串或null未知量。电阻唯一id、已知不同端点a/b、正ohms，可选正rated_watts。数值使用最多9位整数及6位小数的十进制字符串，计算与输出为精确有理数。

每个连通分量至少一个固定电位，拒绝悬浮未知孤岛；孤立固定节点合法。使用KCL电导矩阵求未知电位，平行电阻逐件计数。current_a_to_b正值表示a流向b；功率为I²R，超过额定值才标记over_rating，等于不标。

未知节点电阻外流代数和必须零。固定节点supplied_amps为维持该电位需注入的电流，supplied_watts=电位*注入电流，可负表示吸收。所有固定源总供能必须精确等于电阻发热，总残差零。源逐项功率与电位参考有关，网络总平衡不依赖统一参考平移。

模型只含无源线性电阻和理想固定电位，不含外加电流源、瞬态、频域、电容电感、二极管、热反馈或真实硬件控制。额定功率诊断只比较输入标称值，不提供硬件安全认证。后续仪表读数拟合/元件容差分析可以复用节点端点和电导方程，不是布尔逻辑仿真。全部样例自制；输出存在则拒绝，不覆盖，错误返回2。

# 离线实测数据发布链路

本节约定仪表实测电压（而非网络求解器结果）的离线发布与读取。实现位于 `resistor_flow.measurements`，持久化只使用调用方指定的本地目录与标准库，不引入外部服务，也不改变上文求解链路的任何行为；本链路不导入求解器，任何数值只来自输入的实测读数与接线登记，求解结果不参与填值、筛值或冲突裁决。

## 接口与归属

- `publish(store_dir, request)`：发布新版本。
- `read_version(store_dir, run_id, version)`：按版号读取；未知历史版本抛 `MeasurementError`，绝不回落当前版。
- `read_current(store_dir, run_id)`：一次取当前版。
- `read_evidence(store_dir, run_id, station, row_id, version=None)`：按原始身份取该版固定的证据。
- 全部业务校验与读取失败均抛 `MeasurementError`（`ValueError` 子类）。运行以 `run_id` 隔离，不支持跨运行查询；所有 ID 沿用本仓 ID 规则（`[A-Za-z0-9_:-]{1,64}`）。

发布请求字段：`run_id`、`request_id`、`base_version`、`readings`、`registrations`，首版额外携带 `network`。字段集合为闭合集合，缺字段或多余字段均拒绝。空目录中某运行的起始版本为 0（无观测、无证据、无变更集）；成功发布把运行推进一版，空变更也保留该版证据。

`network` 必须通过上文现有网络输入校验；只取其中电阻 ID 与有序端点 `a/b` 定义测点与正向。首版之后的请求再携带 `network` 一律拒绝，已登记网络不可替换。

## 原始读数与原始身份

每条读数含 `station`、`row_id`、`channel`、`tick`、`raw_volts`。`tick` 为 0..9,999,999 的整数（布尔值不视为整数），所有站共用同一时基。`raw_volts` 沿用有界十进制字符串口径（最多 9 位整数、6 位小数，必须是字符串）。

- 同一运行的原始身份为 `(station,row_id)`，同一运行累计至多 100,000 条唯一读数。
- 同身份同内容重复送达只保留一条；同身份异内容（批内或与历史）拒绝整次发布。身份以外不得推测哪些是重发。
- 每条原始身份在 `raw/<station>/<row_id>.json` 只写一次，任何校验失败都不新增采集行。

## 接线登记与区间匹配

每条登记含 `station`、`channel`、`start_tick`、`end_tick`、`resistor_id`、`positive_node`、`gain`、`offset_volts`。每版登记至多 10,000 条，是该版完整生效的登记集合；更正对历史触发点同样生效，不限本批新增读数。

- 区间为左闭右开 `[start_tick,end_tick)`；`start_tick` 取 0..9,999,999，`end_tick` 取 1..10,000,000，必须非空（`start < end`）。
- 同一站和通道的区间不得重叠，可以相接（前一区间 `end` 等于后一区间 `start`）或留缺失；读数按站/通道查找覆盖其 `tick` 的唯一区间，无覆盖即为未绑定。
- `resistor_id` 必须存在于网络，`positive_node` 必须是该电阻的 `a` 或 `b`，`gain` 必须为正；`gain` 与 `offset_volts` 均按有界十进制字符串读入。

## 标准观测、换算与冲突

每版以截至该版的全部原始读数配合该版完整登记重新计算。匹配后先按 `raw_volts × gain + offset_volts` 精确换算（`fractions.Fraction`，无浮点容差）；正探针接在电阻的 `b` 端时整体反号。换算结果按本仓现有有理数字符串形式交付（整数或 `n/d`）。

标准观测键为 `(tick,resistor_id)`：

- 同键全部已绑定读数换算结果相同：发布一条观测行，`sources` 为完整、稳定排序的原始身份列表（`[station,row_id]` 对）。
- 存在任何不同结果：整键不发布，该键出现在 `conflicts` 中并列出全部原始身份；不择一、不平均、不保留上一版结果。
- 未绑定读数不进入标准观测。

逐身份证据随版本固定，含原始读数、状态（`unbound` / `accepted` / `conflict`）、匹配时所用登记原文、换算值与观测键；读取旧版返回的是该版当时的证据，不随后续更正变化。

## 版本、变更集与读取一致性

每次成功发布返回的快照与 `read_version` 的返回同构：`version`、`observations`、`conflicts`、`evidence`、`changeset`。变更集有源版号 `from_version` 与目标版号 `to_version`，包含：

- `removed`：相对直接前版消失的观测键；
- `upserted`：新增或改变的完整观测行；值相同但来源集合变化也算改变。

应用一次变更集后的消费者观测表必须与目标版标准观测逐行一致；不允许清库重灌或整表重发。一次读取中的版号、观测、原始证据与变更集保证同属一个版本。历史版本目录不可变，读取旧版不依赖调用方重新提供原始资料，新进程与后续更正后仍可读。

## 并发、幂等与提交边界

- 发布以运行级咨询锁串行化；成功必须以 `base_version` 等于当时当前版为前提，两个争用同一底版的不同请求最多一个推进，另一个收到过期底版错误。
- 已成功的 `(run_id,request_id)` 先于一切推进被识别：同一请求内容返回原版号与原版变更集，旧底版也照样重放；同 ID 不同内容报错。请求内容按解析后的结构比较：字典键序不影响身份，数组顺序与数值字符串原文（如 `"2"` 与 `"2.0"`）参与比较。未成功的请求不占用 ID。
- 提交顺序为：不可变原始读数 → 暂存目录内构建完整版本目录并原子改名 → 写请求记录 → 原子切换 `current.json`。进程在任一点中断后重新打开，只能看见完整旧版或完整新版；新版一旦可见，其请求重试身份与历史证据必然已经可用。下次发布（或同请求重试）会清理暂存残骸、补完或摘除孤儿版本目录。
- 任何校验错误、过期底版或幂等冲突都不得改变已提交的原始读数与历史版本。
